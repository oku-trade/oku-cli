# Oku Agent command reference

Generated by `make docs` from the urfave/cli command tree. Do not edit by hand.

### Global options

| Flag | Description | Default |
| --- | --- | --- |
| `--profile` | profile name (default: $OKU_PROFILE or config default) | `` |
| `--network` | network (only mainnet is supported) | `` |
| `--account` | account address for read commands | `` |
| `--json` | write a JSON envelope to stdout | `false` |
| `--timeout` | per-request timeout (max 2m) | `15s` |
| `--input` | read command options from one JSON object in FILE (or - for stdin); max 1 MiB | `` |

## `oku auth login`

Authorize a Privy embedded-wallet agent on the Oku website

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `--api-url` | Oku API origin for the profile created when none exists | `` |
| `--no-open` | print verification URL without opening browser; required without a terminal. With --json, stdout is newline-delimited events: authorization_required, then authenticated, expired or error | `false` |
| `--timeout` | maximum time to wait for authorization | `10m0s` |
| `--credential-store` | Linux: where to keep the credential, file (0600 file, default) or keyring (desktop Secret Service); default $OKU_CREDENTIAL_STORE, else the profile's current store. Ignored on macOS (Keychain) | `` |

## `oku bridge prepare`

Prepare a backend-built transaction bridge

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `--chain` | source EVM chain ID supported by Oku swap, e.g. 42161, 8453, 10, 137 | `` |
| `--from` | input token address, unambiguous symbol, or native (also 0x0 or 0xEeee address) | `` |
| `--to` | output token address, unambiguous symbol, or native (also 0x0 or 0xEeee address) | `` |
| `--amount` | exact input decimal amount or max/all (full onchain balance) | `` |
| `--gas-reserve` | native gas reserve in native units for max/all (default 0.001, Ethereum 0.01) | `` |
| `--slippage-bps` | maximum slippage in basis points, 0-300 | `50` |
| `--recipient` | EVM recipient (default: agent wallet) | `` |
| `--route` | select only this swap router or bridge | `` |
| `--no-intent` | exclude typed-data intent routes | `false` |
| `--max-loss-bps` | swap guardrail: refuse prepare when market loss (excluding the Oku fee) exceeds this many bps (default 500) | `0` |
| `--allow-high-impact` | swap guardrail override: prepare even when the priced loss exceeds --max-loss-bps (small chains, mispriced oracles) | `false` |
| `--destination-chain` | destination EVM chain ID | `` |
| `--intent-id` | optional unique intent ID | `` |
