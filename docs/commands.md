# Oku CLI command reference

Generated by `make docs` from the urfave/cli command tree. Do not edit by hand.

### Global options

| Flag | Description | Default |
| --- | --- | --- |
| `--profile` | profile name (default: $OKU_PROFILE or config default) | `` |
| `--network` | network (only mainnet is supported) | `` |
| `--account` | account address for read commands | `` |
| `--json` | write a JSON envelope to stdout | `false` |
| `--timeout` | per-request timeout (max 2m) | `15s` |

## `oku account summary`

Balances, margin and builder-fee status

## `oku auth revoke`

Revoke this device's Oku API token and delete local credentials

## `oku auth setup`

Enroll this device with an enrollment code from the Oku website

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `--device-name` | name shown on the Oku devices page (default: hostname) | `` |
| `--code-stdin` | read the enrollment code from stdin instead of a prompt | `false` |
| `--resume` | resume polling an interrupted enrollment | `false` |

## `oku auth status`

Show local enrollment status (--verify checks with Oku)

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `--verify` | check the device credential with Oku (requires unlock) | `false` |

## `oku orders cancel`

Cancel an open order: orders cancel --market COIN --order-id OID

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `--market` | market of the order (required) | `` |

### Options

| Flag | Description | Default |
| --- | --- | --- |

## `oku orders prepare`

Prepare a local order intent (no exchange submission; may read market data)

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `--market` | market, e.g. BTC (required) | `` |
| `--side` | buy or sell (required) | `` |
| `--type` | limit or market (required) | `` |
| `--size` | base size as a decimal string (required) | `` |
| `--price` | limit price (limit orders) | `` |
| `--tif` | time in force for limit orders: gtc, ioc, alo | `gtc` |
| `--slippage-bps` | max slippage in basis points from the current mid (market orders, required) | `0` |
| `--reduce-only` | only reduce an existing position | `false` |
| `--intent-id` | caller-chosen idempotency id (default: random) | `` |
| `--expires` | intent lifetime (max 1h) | `5m0s` |

## `oku profiles add`
